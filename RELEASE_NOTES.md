## Козырная Арена 1.4 — ярче и щедрее к отстающим

![Козырная Арена](https://elzhanserikbaev-cloud.github.io/kozyrnaya-arena/cover.jpg)

**Новое**
- **Ярче.** Светлее стол и сукно, сочные цвета портретов на картах, светлее рамки и панели, меньше виньетки.
- **Новый стартовый экран** с веером козырных карт и обложка для ссылок на игру.
- **Козырь в рукаве.** Часть витрины подбирается под ваш стол: копии ваших героев (для ★★) и герои тех же рангов (для пар, троек, фулл-хауса). Чем длиннее серия поражений, тем чаще такие карты попадаются: обычно 51% полезных карт, после 3 поражений подряд 70%.
- **После поражения** первое обновление магазина бесплатно.

Бонусы покерных рук не изменились.

Онлайн-комнаты 1.4 несовместимы с 1.3: обновитесь оба. Android: если стоит старая версия, удалите её перед установкой.

### Первый запуск
Приложение не подписано платным сертификатом, поэтому система спросит подтверждение:
- **Windows:** «Windows защитила ваш компьютер» → «Подробнее» → «Выполнить в любом случае».
- **macOS:** перетащите игру в «Программы», затем правый клик по ней → «Открыть» → «Открыть». Если пишет «повреждено», выполните в Терминале:
  `xattr -cr "/Applications/Kozyrnaya Arena.app"`
- **Android:** при установке телефон попросит разрешить установку из этого источника (браузера или файлового менеджера) — разрешите. Приложение не из Google Play, поэтому Play Защита может предупредить: «Установить всё равно».
- **Ubuntu (AppImage):** `chmod +x KozyrnayaArena-*.AppImage`; если не стартует: `sudo apt install libfuse2`. Либо поставьте `.deb`: `sudo apt install ./KozyrnayaArena-*.deb`.
