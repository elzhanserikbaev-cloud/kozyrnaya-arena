## Козырная Арена 1.1 — «Подпольный турнир» (21+)

Игра стала мрачнее и честнее.

**Новое**
- Новый стиль: подпольный карточный притон, тёмные карты-таро с гравюрными портретами, бордовый бархат и золото.
- **37 героев** вместо 25: наёмники, вампиры, некроманты, инквизиторы, чумной доктор, палач, Жнец и Демон крови.
- Новые способности героев: **Мор** (травит всех врагов) и **Поднять мёртвых** (возвращает павшего союзника в бой).
- **6 новых заклинаний**: Кровавый пакт, Проклятие, Цепная молния, Восстание из гроба, Отравленное вино, Гильотина. Всего 13 заклинаний и 7 усилений.

**Баланс**
- Комбинацию собирают только **разные** герои: копии одного героя считаются одной картой. Каре из двух пар копий больше не собрать, теперь оно возможно только с Джокером.
- Бонусы рук снижены и выстроены по редкости: пара +6% АТК … фулл-хаус +18%, каре +22%.
- Союзы мастей тоже считают только разных героев, их бонусы снижены (криты, лечение, щит, здоровье).
- В симуляции 12 партий более сильная рука выигрывает около 60% боёв: комбинации важны, но исход решают не только они.

Онлайн-комнаты версии 1.1 несовместимы с 1.0: всем игрокам нужно обновиться.

### Первый запуск
Приложение не подписано платным сертификатом, поэтому система спросит подтверждение:
- **Windows:** «Windows защитила ваш компьютер» → «Подробнее» → «Выполнить в любом случае».
- **macOS:** перетащите игру в «Программы», затем правый клик по ней → «Открыть» → «Открыть». Если пишет «повреждено», выполните в Терминале:
  `xattr -cr "/Applications/Kozyrnaya Arena.app"`
- **Ubuntu (AppImage):** `chmod +x KozyrnayaArena-*.AppImage`; если не стартует: `sudo apt install libfuse2`. Либо поставьте `.deb`: `sudo apt install ./KozyrnayaArena-*.deb`.
